# 🌸 Bloom __________ لعبة Bloom

## Plant Care Simulation Game __________ لعبة محاكاة العناية بالنبات

---

# 📖 About __________ نبذة

Bloom is a simple Python game where the player takes care of a plant until it grows into a beautiful flower.
__________
Bloom هي لعبة بسيطة بلغة Python يقوم فيها اللاعب بالعناية بنبتة حتى تنمو وتصبح زهرة جميلة.

---

# 🎯 Game Objective __________ هدف اللعبة

Take care of your plant by:
__________
اعتنِ بالنبتة عن طريق:

- 💧 Water Plant     __________ سقي النبتة
- ☀ Give Sunlight    __________ إعطاء ضوء الشمس
- 🛒 Buy Useful Items __________ شراء الأدوات
- 🌙 End Day          __________ إنهاء اليوم
- 🎲 Random Events    __________ أحداث عشوائية

Reach the final growth stage and make your plant bloom.
__________
والهدف النهائي هو جعل النبتة تزهر.
